1. Move `docs/features/{NNN}-{slug}.md` into this folder (same filename). Do **not** leave a stub in `docs/features/`.
2. Repair links to the old path (moved FRED, index, other FREDs, entrypoint, READMEs). Depth under this folder is one extra `../`.
3. Update [OPEN-FRED-INDEX.md](../OPEN-FRED-INDEX.md): drop the open row; add Recently closed; bump **Open** / **Implemented** counts; refresh Updated; adjust mermaid/DAG if present.
4. Add a row to the Closed table below.
